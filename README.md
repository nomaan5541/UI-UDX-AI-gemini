# Gemini Chat GUI Application

A simple, Python-based graphical user interface (GUI) application for interacting with the Google Gemini API. This project uses **CustomTkinter** for a modern, cross-platform look and feel, and the **Google Gen AI SDK** for the backend chat functionality.

---

## 🚀 Features

* **CustomTkinter GUI:** Clean, modern interface supporting light/dark mode.
* **Authentication System:** Simple user registration and login system.
* **Secure API Handling:** Uses a `.env` file to securely store and load the Gemini API Key.
* **Persistent Chat:** Once logged in, the application initiates a chat session with the `gemini-2.5-flash` model.

---

## 💻 Prerequisites

Before running the application, ensure you have the following:

1.  **Python 3.8+** installed on your system.
2.  A **Gemini API Key** (available from Google AI Studio).
